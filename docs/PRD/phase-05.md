# Phase 5 PRD — 進階強化（Enhancement）

> 目標：補上「聽得到的和弦」與「看得到的累積」——和弦合成示範音、練習統計儀表板、自訂進行編輯器，並做整體體驗打磨。
> 結束狀態：RCS 成為完整閉環：練（三條線）→ 聽（示範音）→ 看見進步（統計）→ 自造教材（自訂進行）。

## 1. 範圍

### In scope
- Web Audio 和弦合成示範音（接進和弦線跟練）
- 練習統計儀表板（吃 Phase 2 起累積的 practiceLog）
- 自訂進行編輯器（級數輸入 → 跟練）
- 體驗打磨：鍵盤快捷鍵、無障礙、效能、錯誤回報
- 設定匯出/匯入（JSON 檔，含自訂 pattern/進行與練習日誌備份）

### Out of scope（保持未來擴充清單）
- 帳號/雲端、麥克風判定、採樣音源、左手模式、自訂調弦、淺色主題、PWA

## 2. 功能需求

### F5-1 和弦合成示範音
1. 合成器：多音 OscillatorNode（三角波/鋸齒混合 + lowpass + ADSR），模擬撥彈即可，不追求擬真吉他音。
2. 發聲模式（和弦線跟練頁可選）：
   - `off`：維持純 click（預設，尊重「click 為主」原則）
   - `pad`：每次和弦切換時輕聲鋪底全小節
   - `strum`：每小節第 1 拍模擬掃弦（音符 10–20ms 錯開）
3. Voicing 策略：中音域 close voicing（root 3rd 7th 優先），聲部連接就近移動——由 theory 引擎給音、audio 層只管發聲。
4. 音量獨立於 click，混音不蓋拍點；行動裝置效能驗證（複音數上限 6）。

### F5-2 練習統計儀表板
1. 總覽卡：本週練習時長、連續練習天數（streak）、累計時長。
2. 圖表：近 4 週每日練習時長長條圖（依三條線分色堆疊）；各模組時長佔比。
3. 明細：練習日誌列表（日期、模組、時長、BPM），可依線別篩選。
4. BPM 進步線：同一模組＋同參數的歷史 BPM 折線（例：16 分 FUNK pattern 從 80 → 100 的軌跡）。
5. 資料管理：清除紀錄（需確認）、匯出 JSON。

### F5-3 自訂進行編輯器
1. 輸入：級數記法文字（沿用 F3-2 parser，白名單文法 + 即時錯誤提示），或在五度圈上點選和弦逐一加入。
2. 設定：每和弦小節數、BPM、（可選）12 調循環開關。
3. 預覽：展開為和弦序列（任選調試看），存入 localStorage 後出現在和弦線模組列表，跟練體驗與內建 preset 完全相同（含指板同步、五度圈 highlight）。
4. 管理：改名、複製、刪除、匯出/匯入。

### F5-4 體驗打磨
1. **鍵盤快捷鍵**：space 播放/停止、↑↓ 調 BPM（±1 / shift±10）、← → 換 preset；快捷鍵說明面板（`?`）。
2. **無障礙**：全站鍵盤可達、SVG 組件 aria 標籤、色彩對比複核；`prefers-reduced-motion` 時脈衝改為非動畫高亮。
3. **效能**：指板/五度圈/節奏譜渲染 profiling（60fps 目標）；首屏 bundle 分包（練習模組 lazy load）。
4. **穩定性**：全域 error boundary + localStorage 損毀自復原（備援預設值）；版本 migration 實測。

## 3. 驗收標準（Phase DoD）
- [ ] 和弦示範音三模式可切換，開啟後 click 拍點依然清晰可辨；手機無爆音/斷音
- [ ] 儀表板正確反映歷史日誌（含 Phase 2–4 舊資料 migration）
- [ ] 自訂進行：建立 → 跟練 → 匯出 → 匯入還原，全流程可用
- [ ] 快捷鍵與 a11y 檢核清單通過；Lighthouse a11y ≥ 95
- [ ] 全站 bundle：首屏 < 200KB gz（音訊零資源的優勢要守住）

## 4. 風險
| 風險 | 對策 |
|---|---|
| 合成和弦音在手機喇叭上糊掉蓋住 click | click 頻段（1kHz+）與 pad 頻段（lowpass < 800Hz）錯開；strum 模式預設音量低 |
| 統計圖表拉入重量級圖表庫破壞 bundle 目標 | 自繪 SVG 長條/折線（資料量小，不需要圖表庫） |
| 自訂進行 parser 錯誤訊息不友善 | 即時逐 token 驗證 + 錯誤位置高亮 + 範例提示 |
