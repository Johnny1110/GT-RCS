# RCS 設計系統（Design System）

> **文件地位：規範性。** UI 實作的視覺決策以本文件為準，與 `docs/architecture.md` 同級。
> 視覺稿（可互動 mockup）：Artifact「RCS 介面設計規範」。
> Token 落點：`src/assets/main.css`（CSS）與 `src/core/colors/degreeColors.ts`（TS，12 音程色）。

## 1. 設計概念——「樂器面板」

介面是深夜琴房裡的黑色器材面板：全部黑白灰、無陰影、無漸層。
**色彩只屬於音樂**——畫面上任何有顏色的東西都是一個音。四條系統性規則：

1. **色彩即音高資訊**：12 音程色只出現在音點、五度圈調內和弦、組成音列。節奏、結構、狀態一律灰階。
2. **選取即反白**：作用中分頁、segmented 選項、當前小節、主音扇形——一律黑白反轉（白底黑字）。不存在 accent 色。
3. **面板式層次**：層次以亮度表達（950 頁面 → 900 面板 → 800 懸浮），邊框一律 1px `ink-700`。禁止 box-shadow。
4. **音樂數據等寬**：BPM、小節數、度數、拍號、和弦名用 mono + `tabular-nums`，數字跳動不位移。

### 12 音程色

定義於 `src/core/colors/degreeColors.ts`（唯一真相）＋ `main.css` `--color-degree-*`（需同步）。
語意色規則：**沒有語意色**。成功/錯誤/警告以文字與反白表達；**危險操作不用紅色**（紅=b2 音程），
用反白按鈕＋明確動詞＋二次確認。

## 3. 字體排印

不引入外部字體（零載入、跨平台穩定）：

- **UI 文字**：`system-ui` stack（zh-TW 落在 PingFang TC / Noto Sans TC）
- **音樂數據 / micro 標籤**：`ui-monospace` stack（SF Mono / Cascadia / Menlo）

| 角色 | 規格 | 用途 |
|---|---|---|
| display | 40 / 700 | 稀少，landing 標題 |
| h1 | 24 / 650 | 頁面標題 |
| h2 | 18 / 650 | 區塊標題 |
| body | 15 / 400 / lh 1.7 | 內文、知識卡 |
| small | 13 / 400 | 說明、圖例 |
| micro | mono 11 / 400 / tracking .18em / 大寫 | 控制群標籤（KEY·SCALE·BPM） |
| data | mono / 700 / tabular-nums | BPM 26–28、和弦名 18、統計數字 |

## 4. 形狀與間距

- **圓角紀律**：控制元件 4px、面板 8px、音點與拍燈正圓、chip 全圓角。不用 rounded 其他值。
- **間距**：4px 基準；元件內距 8/12/16/20；區塊間距 24/40。
- **邊框**：一律 1px `ink-700`；Transport 控制台用 2px 上邊框與內容切開。

## 5. 元件規範

### 按鈕
- `primary`：反白（`ink-50` 底、`ink-950` 字、650 字重）——**每畫面最多一顆**（通常是播放）。
- `default`：`ink-800` 底、`ink-700` 框、hover 升至 `ink-700`。
- `ghost`：透明，hover `ink-800`。
- `disabled`：`ink-850` 底、`ink-600` 字。
- focus-visible：`2px solid ink-50` outline、offset 2px（全站一致）。

### Segmented control
`ink-900` 底 + `ink-700` 框 + 2px 內距；選中片段反白（`ink-50` 底 `ink-950` 字、mono 700）。
拍號、細分、標記模式、風格選擇全用此元件。

### 音點（Note Dot）——全站原子元件
- 底色 = `colorForInterval()`；文字 = 度數或音名（mono 700，`textHex` 深色壓亮底）。
- 主音 = 白底黑字。尺寸三級：**22px**（指板密集）/ **28px**（標準）/ **40px**（組成音列）。
- 指板、五度圈、組成音列、和弦 timeline 共用同一語言，不另造形狀。

### 指板（Fretboard 視覺規格，實作於 F1-4）
- 等距格寬（資訊優先，非真實比例）；string 1（高音 e）在上。
- 琴枕 4px `ink-500`；琴衍 1.5px `ink-700`；弦 0.8→2.2px 漸粗（`ink-600`）。
- 指位記號 `ink-800` 圓點（3/5/7/9/15/17/19/21 單、12 雙）；格數標記 mono 10px `ink-600`。

### 五度圈（視覺規格，實作於 F3-1）
- 扇形灰階：調外 `ink-900`／調內 `ink-800`／主音反白；描邊 1px `ink-700`。
- 調內和弦於標籤下方加 4.5px 度數色點（相對主音：C 調的 G 得 5-灰、F 得 4-青、Am 得 6-粉…）。
- 當前和弦：2px 白圈，脈衝與 click 同步；中心洞顯示調名 + vii° 徽章。

### 節奏譜（RhythmSheet，F4-2 已實作）
**完全灰階**（節奏無音高）：重音=實白方格、一般=實灰（`ink-500`）、鬼音=1.5px 虛線空心、
休止=`ink-950` 暗格帶中心點（譜面板本身是 `ink-900`，休止若同色會整個消失）。
游標=2px 白框 outline。格 38px 為上限、拍內 gap 6px、拍間 gap 16px、
計數列 mono 11px（拍首 `ink-100` 700、其餘 `ink-500`）。
窄螢幕先把格寬壓到 20px 下限，仍放不下才在譜的容器內橫向捲動（頁面本身永不橫捲），
游標自動跟捲。

### Transport 控制台
練習頁常駐底部：播放鍵（44px 白圓）→ BPM（mono 26 + 滑桿）→ 拍號/細分 segmented →
拍燈（10px 圓點，當前拍亮白，吃 TickBus）→ 右端三音色音量。
窄螢幕以 flex 換行排列（播放／BPM 維持第一列），不隱藏任何控制——手機上仍需能調整拍號與音量。
拍號與細分播放中也可切換，由 core Transport 排到下一個小節線生效（Phase 4 起）。
掛著節奏 pattern 時兩者改由 pattern 決定，該區轉為唯讀顯示（拍號 · 細分 + 「由節奏譜決定」）。
細分標籤是音符名稱，隨拍號分母改變（4/4 的一拍兩格＝8，6/8 的一拍兩格＝16）。

## 6. 動態與可及性

- 動態只有三處：拍燈、五度圈當前和弦脈衝、節奏譜游標——全部由 TickBus 驅動（架構規則：禁止 CSS 動畫自走節拍）。
- `prefers-reduced-motion`：脈衝改為非動畫的常亮高亮。
- 音點永遠有度數文字（顏色是輔助編碼）；焦點環全站一致；對比以 WCAG AA 為底線。
- Icon：內聯 SVG 線條（1.5px stroke、`currentColor`），不引入 icon font。

## 7. Do / Don't

**Do**：色彩只給音高；選取用反白；數據用 mono；層次用亮度；危險操作反白＋確認。
**Don't**：任何 accent 色（含連結藍、成功綠、錯誤紅）；陰影／漸層／毛玻璃；音程色用於按鈕或裝飾；
紅色表達危險；外部字體；非 4/8px 的圓角。
