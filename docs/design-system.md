# RCS 設計系統（Design System）

> **文件地位：規範性。** UI 實作的視覺決策以本文件為準，與 `docs/architecture.md` 同級。
> 視覺稿（可互動 mockup）：Artifact「RCS 介面設計規範」。
> Token 落點：`src/assets/main.css`（CSS）與 `src/core/colors/degreeColors.ts`（TS，12 音程色）。

## 1. 設計概念——「樂器面板」

介面是深夜琴房裡的黑色器材面板：全部黑白灰、無陰影、無漸層。
**色彩只屬於音樂**——畫面上任何有顏色的東西都是一個音。四條系統性規則：

1. **色彩即音高資訊**：12 音程色只出現在音點、五度圈調內和弦、組成音列。節奏、結構、狀態一律灰階。
2. **選取即反白**：作用中分頁、segmented 選項、當前小節、主音扇形——一律黑白反轉（白底黑字）。不存在 accent 色。
3. **面板式層次**：層次以亮度表達（950 頁面 → 900 面板 → 800 懸浮），邊框一律 1px `ink-700`。禁止 box-shadow。
4. **音樂數據等寬**：BPM、小節數、度數、拍號、和弦名用 mono + `tabular-nums`，數字跳動不位移。

## 2. 色彩 Token

### ink 灰階（微冷 zinc 系；深色單一主題——產品決策，淺色列 backlog）

| token | hex | 用途 |
|---|---|---|
| `ink-950` | `#101013` | 頁面底 |
| `ink-900` | `#17171B` | 面板底 |
| `ink-850` | `#1C1C21` | disabled 底 |
| `ink-800` | `#222228` | hover / 懸浮層 / 調內扇形 |
| `ink-700` | `#2E2E36` | 邊框、琴衍、灰階刻線 |
| `ink-600` | `#44444E` | 弦、圖表格線——**結構專用，不用於文字** |
| `ink-500` | `#6E6E78` | 琴枕、圖形描邊——**結構專用，不用於文字** |
| `ink-400` | `#8B8B96` | **文字的最低亮度**：micro 標籤、說明、次要文字 |
| `ink-300` | `#ADADB8` | 輔助內文 |
| `ink-100` | `#DDDDE3` | 一般內文、強調的 micro 標籤 |
| `ink-50`  | `#F4F4F6` | 主文字、反白底、播放游標、拍燈 |

#### 文字對比下限（F5-4 複核結果）

在 `ink-900` 面板上：`ink-600` 只有 **1.86:1**、`ink-500` 只有 **3.54:1**，兩者都不到
WCAG AA 對一般文字的 4.5:1；`ink-400` 是 **5.30:1**，剛好過關。因此：

- **任何帶資訊的文字（含 SVG `<text>`）一律 ≥ `ink-400`**，不論字級多小。
- `ink-500` / `ink-600` 退為結構色（弦、琴枕、格線、描邊）。
- 層次改由**字級、字重、mono 與否**表達，不再靠把文字調暗——這比亮度分級更耐用。
- 兩個例外，兩者都不是「暗底上的資訊文字」：反白狀態的深色字（白底 `ink-600`）、
  disabled 狀態（無障礙規範不要求 disabled 元件達標）。純裝飾字元（如分隔用的 `·`）
  標 `aria-hidden="true"`，讓它誠實地離開無障礙樹，而不是假裝自己看得見。

### 指位記號金色

`--color-inlay`（`main.css`）。唯一的非音高色彩，只用在指板的指位記號圓點，理由見 §5。

### 12 音程色

定義於 `src/core/colors/degreeColors.ts`（唯一真相）＋ `main.css` `--color-degree-*`（需同步）。
語意色規則：**沒有語意色**。成功/錯誤/警告以文字與反白表達；**危險操作不用紅色**（紅=b2 音程），
用反白按鈕＋明確動詞＋二次確認。

## 3. 字體排印

不引入外部字體（零載入、跨平台穩定）：

- **UI 文字**：`system-ui` stack（zh-TW 落在 PingFang TC / Noto Sans TC）
- **音樂數據 / micro 標籤**：`ui-monospace` stack（SF Mono / Cascadia / Menlo）

| 角色 | 規格 | 用途 |
|---|---|---|
| display | 40 / 700 | 稀少，landing 標題 |
| h1 | 24 / 650 | 頁面標題 |
| h2 | 18 / 650 | 區塊標題 |
| body | 15 / 400 / lh 1.7 | 內文、知識卡 |
| small | 13 / 400 | 說明、圖例 |
| micro | mono 11 / 400 / tracking .18em / 大寫 | 控制群標籤（KEY·SCALE·BPM） |
| data | mono / 700 / tabular-nums | BPM 26–28、和弦名 18、統計數字 |

## 4. 形狀與間距

- **圓角紀律**：控制元件 4px、面板 8px、音點與拍燈正圓、chip 全圓角。不用 rounded 其他值。
- **間距**：4px 基準；元件內距 8/12/16/20；區塊間距 24/40。
- **邊框**：一律 1px `ink-700`；Transport 控制台用 2px 上邊框與內容切開。

## 5. 元件規範

### 按鈕
- `primary`：反白（`ink-50` 底、`ink-950` 字、650 字重）——**每畫面最多一顆**（通常是播放）。
- `default`：`ink-800` 底、`ink-700` 框、hover 升至 `ink-700`。
- `ghost`：透明，hover `ink-800`。
- `disabled`：`ink-850` 底、`ink-600` 字。
- focus-visible：`2px solid ink-50` outline、offset 2px（全站一致）。

### 文字輸入（`.rcs-input`）
`ink-950` 底 + 1px `ink-700` 框 + 4px 圓角；placeholder `ink-600`（不帶資訊，允許最弱）。
`aria-invalid="true"` 時邊框提亮到 `ink-400`——**不用紅色**（紅是 b2 音程色）。
核取方塊 `.rcs-check` 與滑桿 `.rcs-range` 同樣以 `accent-color: ink-50` 保持灰階。

### Segmented control
`ink-900` 底 + `ink-700` 框 + 2px 內距；選中片段反白（`ink-50` 底 `ink-950` 字、mono 700）。
拍號、細分、標記模式、風格選擇全用此元件。

### 音點（Note Dot）——全站原子元件
- 底色 = `colorForInterval()`；文字 = 度數或音名（mono 700，`textHex` 深色壓亮底）。
- 主音 = 白底黑字。尺寸三級：**22px**（指板密集）/ **28px**（標準）/ **40px**（組成音列）。
- 指板、五度圈、組成音列、和弦 timeline 共用同一語言，不另造形狀。

### 指板（Fretboard 視覺規格，實作於 F1-4）
- 等距格寬（資訊優先，非真實比例）；string 1（高音 e）在上。
- 琴枕 4px `ink-500`；琴衍 1.5px `ink-700`；弦 0.8→2.2px 漸粗（`ink-600`）。
- 指位記號 r5.5 **亮金色**（`--color-inlay` `#E3B341`）圓點（3/5/7/9/15/17/19/21 單、12 與 24 雙），畫在最底層。
  這是**全站唯一不屬於音高的顏色**，是 §1 規則 1 的明列例外，理由三條：
  指位記號不是資料而是**琴本身**（實體吉他的貝殼／金屬鑲嵌就是這個顏色，一眼就知道它不是一個音）；
  灰階版本在面板上只有 `ink-600` 的 **1.86:1**，一路調暗到「不搶眼睛」也就同時調到「數不到第 12 格」，
  而數把位正是它存在的唯一理由（金色是 **9.2:1**）；
  它與 12 音程色沒有一個同色——最接近的是 `7` 的亮黃 `#FFD54F`，而指位記號只有音點的一半大、
  畫在弦與弦之間、永遠沒有文字，三個特徵同時不同。
  金色只給圓點：**格數標記維持灰階**，數字跟著變金會讓整條格數列開始跟音點搶眼睛。
- 格數標記 mono 10px：一般 `ink-400`，指位記號所在格 `ink-100`（依 §2 文字對比下限，不用 `ink-600`）。

#### 把位框
全指板音點有 40（和弦）到 90（七音音階）個，不分組就看不出指型。**框一律灰階**——色彩只屬於音高。

共通視覺：
- 框：1.5px `ink-500` 圓角 8px，畫在音點下層；左右各內縮 2.5px，相鄰把位才看得出分隔。
- 標籤：框左上方 mono 10px 700 `ink-400`。
- 聚焦時該框 2px `ink-500`，框外音點 opacity 0.12。
- 有把位框時，指板下方的控制列由「把位跳轉固定格號」換成把位選單（選中即反白）；
  點框或點選單都會把該把位捲進可視範圍。

兩種模式，差別在把位系統本身重不重疊：

| | `tile`（和弦線） | `focus`（音階線） |
|---|---|---|
| 把位關係 | 互不重疊 | 天生重疊（相鄰把位共用兩三格） |
| 畫幾個框 | 全部一起畫 | 只畫聚焦的那一個；沒選＝不畫 |
| 標籤內容 | 根音格號（含空弦的標「空弦」） | 錨定音的**度數**（`1` 的框＝根音起的指型） |
| 未聚焦時的音點 | 框外 opacity 0.26 | 全亮（維持原本的全指板呈現） |
| 未聚焦框 | 1px `ink-800` | 不畫 |

音階線在指板下方多一行 `text-xs ink-500` 提示，說明框住的範圍手不用移動就走得完整個音階。

#### 互動（回想測驗，F7-4）
- **命中層**：`selectable` 時每一格鋪一個透明圓，半徑＝音點的 1.4 倍（直徑約 30px）。
  畫在最上層——音點與把位框會先吃掉點擊。不可見但可點，所以座標寫成 `data-hit-string`／
  `data-hit-fret`，否則連除錯都看不出誰是誰。
- **題目標記**：2px `ink-50` 空心圈，半徑＝音點 +2。**不帶標記也不帶顏色**——
  顏色只屬於已經知道的音，題目還沒答出來就不該有顏色。
- **答對的音點用真實度數色**，不是統一的「正確綠」。答對的獎勵就是那個顏色，
  它同時複習了全站的 12 色 mapping；而綠色是 `2` 度的顏色，拿來當狀態色會污染色彩系統。

### 五度圈（視覺規格，實作於 F3-1）
- 扇形灰階：調外 `ink-900`／調內 `ink-800`／主音反白；描邊 1px `ink-700`。
- 調內和弦於標籤下方加 4.5px 度數色點（相對主音：C 調的 G 得 5-灰、F 得 4-青、Am 得 6-粉…）。
- 當前和弦：2px 白圈，脈衝與 click 同步；中心洞顯示調名 + vii° 徽章。
- **可點扇形**（`.rcs-circle-hit`）：hover 只把描邊提亮到 `ink-400` 並加粗到 2px，**不動填色**
  ——填色是資訊（調內／調外／主音），hover 換掉它會讓主音那格從反白翻成深色。
  焦點環走全站的 `:focus-visible`。跟練畫面只開放外圈（切換 Root），
  編輯器內外圈都開放（輸入和弦）；不可點的環維持原樣，沒有 hover 也沒有 tab 停留。
- 可點時圈下方一行 mono 11px `ink-500` 說明點下去會發生什麼——新功能沒有提示等於沒有。

### 和弦時間軸（ChordTimeline，F3-3 起；強制切換後改版）
- 顯示的是**當前這一段的每一個和弦**（固定調＝整個進行，12 調循環＝這個調的小節），
  不是滾動視窗。格子位置固定、游標在上面移動——與節奏譜同一種讀法，跟練時眼睛不必追著格子跑。
- 四狀態：當前=反白（`ink-50` 底 `ink-950` 字）、下一個=`ink-500` 虛線框、
  之後=`ink-700` 實線框、已過=`ink-800` 框 + opacity 0.5。
- 可點時每一格是 `<button>`，hover 邊框提亮到 `ink-500`（已過的格子同時回到不透明）；
  當前那一格帶 `aria-current`，不做 hover——它已經是反白的最高狀態。

### 琶音音列（七和弦琶音模組）

與音階總覽的組成音列是同一個元件語言（40px 音點 + 下方度數 mono 11px），差別在**它是順序**：
由左到右就是要彈的順序，上下行會重複中間的音（`1 3 5 b7 5 3` 是六格不是四格）。

- **現在該彈的那一個**加 2px `ink-50` 外環（`ring-2` + `ring-offset-2`）——與五度圈的當前和弦白圈、
  指板的題目標記同一種標記語言：**白圈永遠是「就是這個」**，顏色仍然只屬於音高。
  未播放時不畫外環：沒有「現在」就不給假的高亮。
- 指板上同步用 `marks` 圈出這個音的所有位置；聚焦某個把位時只圈框內的（框外圈起來只是雜訊）。
- 指板的把位選單在這個模組記的是**錨定弦**：換調時框跟著新根音走，使用者能拿同一個指型走完 12 調。
- 音序除不盡小節格數時（6 音對 4 格），音列下方一行 mono `ink-400` 說明它會在小節線被切斷、
  以及怎麼對齊。**限制要說出來**，否則使用者以為是壞掉而不是設定問題。

### 節奏譜（RhythmSheet，F4-2 已實作）
**完全灰階**（節奏無音高）：重音=實白方格、一般=實灰（`ink-500`）、鬼音=1.5px 虛線空心、
休止=`ink-950` 暗格帶中心點（譜面板本身是 `ink-900`，休止若同色會整個消失）。
游標=2px 白框 outline。格 38px 為上限、拍內 gap 6px、拍間 gap 16px、
計數列 mono 11px（拍首 `ink-100` 700、其餘 `ink-500`）。
窄螢幕先把格寬壓到 20px 下限，仍放不下才在譜的容器內橫向捲動（頁面本身永不橫捲），
游標自動跟捲。

### 圖表（統計儀表板，F5-2 已實作）
**完全灰階**：統計不是音高。三條線靠亮度分——節奏 `ink-600`／和弦 `ink-400`／音階 `ink-100`。
- 自繪 SVG，不引圖表庫（首屏 bundle 是硬指標）；座標一律來自 `components/charts/geometry.ts`。
- 長條圖：y 軸 3 條 `ink-800` 格線、刻度進位到 1／2／5 × 10^n；沒練的日子畫成 0 高度的空位，
  不擠掉——否則「這週只練兩天」會被畫成「天天都練」。x 軸每 7 天標一次日期。
- 折線圖（BPM 進步）：y 軸**不從 0 起算**（80→100 壓在 0–300 的軸上是一條平線），
  四邊留白讓端點的圓不被切掉；終點 `ink-50`、其餘 `ink-400`。

### 快捷鍵說明面板（F5-4）
`?` 或控制列右端的 `?` 鈕開啟。`ink-950/80` 遮罩 + `ink-900` 面板，`role="dialog"` +
`aria-modal`，開啟時焦點移到關閉鈕，Esc 關閉。按鍵以 `<kbd>`（`ink-800` 底 `ink-700` 框）呈現。

### 內容頁（知識條目、知識索引、法遵頁，F6-5 已實作）
唯一以**閱讀**為主的版型，所以規則與練習頁不同：

- 內文欄寬 `max-w-[65ch]`，行高 `leading-7`，內文 `ink-300`、粗體強調 `ink-50`。
  這是全站唯一容許長段落的地方；練習頁的文字一律短句。
- 索引頁用 2 欄卡片（`sm:grid-cols-2`），卡片＝標題 `ink-50` + 摘要 `ink-400`，
  邊框 `ink-700` → hover `ink-500`。與首頁的模組卡同一種語言，讓「可點的方塊」全站只有一種樣子。
- 條目頁的結構固定為：麵包屑 → h1 → 內文 → 同類條目 → 廣告版位。
  同類條目是外框按鈕列（`ink-700` 框、`ink-300` 字），不是卡片——它是導覽不是內容。
- **這一份版型會被建置期預渲染成靜態 HTML**（`build/renderContent.ts`）。
  改動這裡的 class 時要同步改那邊，否則 Vue 掛載的瞬間會看到版型跳動。

### 廣告版位（F6-3 已實作）
廣告是這個設計系統裡唯一不受控的視覺元素，所以規則是**圍堵**而不是美化：

- **只出現在三個地方**：首頁底部、知識頁底部、統計頁底部。任何會播放節拍的畫面上不存在廣告容器
  （不是隱藏——是根本沒有）。白名單在 `src/config/ads.ts`，測試會擋下指向練習模組的版位。
- 容器以 `.rcs-ad` 保留固定高度（首頁／知識 280px、統計 250px，行動與桌機各一組），
  載入前後同高 → CLS = 0。
- 上方一行 `ink-400` mono 小標「廣告 / Advertisement」——讀者要能一眼分辨哪裡是內容、哪裡不是。
- 未投放（`data-ad-status="unfilled"`）或被攔截器擋掉：**整塊移除**，不留白、不出提示。
  「請關閉廣告攔截器」這種提示不在這個產品裡。

### 頁尾（F6-4 已實作）
每一頁都有，`ink-800` 上框線。左側是知識索引與三份法遵頁的連結（`ink-400` → hover `ink-100`），
右端一行 mono `ink-400` 的「練習紀錄只留在你的瀏覽器」——這句話是產品主張，放在每一頁的角落。
「Cookie 設定」按鈕只在 CMP 真的提供撤回入口時出現；按下去沒反應的按鈕比沒有按鈕更糟。

### Transport 控制台
練習頁常駐底部：播放鍵（44px 白圓）→ BPM（mono 26 + 滑桿）→ 拍號/細分 segmented →
拍燈（10px 圓點，當前拍亮白，吃 TickBus）→ 右端三音色音量。
窄螢幕以 flex 換行排列（播放／BPM 維持第一列），不隱藏任何控制——手機上仍需能調整拍號與音量。
拍號與細分播放中也可切換，由 core Transport 排到下一個小節線生效（Phase 4 起）。
掛著節奏 pattern 時兩者改由 pattern 決定，該區轉為唯讀顯示（拍號 · 細分 + 「由節奏譜決定」）。
細分標籤是音符名稱，隨拍號分母改變（4/4 的一拍兩格＝8，6/8 的一拍兩格＝16）。

## 6. 動態與可及性

- 動態只有三處：拍燈、五度圈當前和弦脈衝、節奏譜游標——全部由 TickBus 驅動（架構規則：禁止 CSS 動畫自走節拍）。
- `prefers-reduced-motion`：脈衝改為非動畫的常亮高亮。
- 音點永遠有度數文字（顏色是輔助編碼）；焦點環全站一致；對比以 WCAG AA 為底線。
- Icon：內聯 SVG 線條（1.5px stroke、`currentColor`），不引入 icon font。

## 7. Do / Don't

**Do**：色彩只給音高；選取用反白；數據用 mono；層次用亮度；危險操作反白＋確認。
**Don't**：任何 accent 色（含連結藍、成功綠、錯誤紅；唯一例外是指板的指位記號金色，見 §5）；
陰影／漸層／毛玻璃；音程色用於按鈕或裝飾；
紅色表達危險；外部字體；非 4/8px 的圓角；**在任何會播放節拍的畫面上放廣告容器**；
用「請關閉廣告攔截器」之類的提示填補收合掉的版位。
